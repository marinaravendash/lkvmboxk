## 🛠 Troubleshooting

### Disc burning failed

```powershell
# Reduce burn speed
# Burn slower (8x instead of 16x) reduces errors

# Check media quality
# Use brand-name discs (Verbatim, Sony) avoiding cheap media

# Update firmware
# Download latest DVD/Blu-ray drive firmware from manufacturer
```

### Video export quality poor

```powershell
# Increase bitrate
# Export Settings > Video Bitrate = 15,000 kbps (1080p) or 35,000 kbps (4K)

# Check source quality
# Upscaling 720p to 4K doesn't improve quality—match export to source

# Use H.265
# H.265/HEVC codec better quality at same file size vs H.264
```

### Conversion taking too long

```powershell
# Enable GPU acceleration
# Settings > Hardware Acceleration = NVIDIA/AMD

# Lower resolution
# Convert 4K to 1080p if device doesn't support 4K

# Close background apps
# Free CPU/GPU resources for faster encoding
```
